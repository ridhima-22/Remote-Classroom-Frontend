# Remote Classroom UI for Rural Colleges

This repository contains the highly complex frontend architecture for a simulated learning platform. This project showcases advanced React.js skills and UI development, built using Vite.

## Technologies Used
* React.js (with Hooks, React Router)
* HTML, CSS, JavaScript
* Vite

## Key Features Demonstrated
* Component-based design for scalability (e.g., Header, Course Card, Auth Forms).
* Dynamic content rendering and secure route protection.
* User Authentication Flow (Client-side simulation).
* Fully Responsive UI (designed for mobile viewing).

## How to Run Locally
1.  Clone the repository: `git clone https://github.com/ridhima-22/Remote-Classroom-Frontend.git`
2.  Navigate to the project directory: `cd Remote-Classroom-Frontend`
3.  Install dependencies: `npm install`
4.  Start the application: `npm run dev`
